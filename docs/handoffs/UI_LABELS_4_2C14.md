# 4.2c14 — Terminologie d'interface

Décision explicite du mainteneur : supprimer la mention « MAIN » dans les intitulés de l'interface Orchestrator.

La carte « Assistant MAIN — disponibilité IA » devient « Assistant — disponibilité IA ». Un test protège les trois templates actifs de l'Orchestrator contre la réintroduction de ce terme.

Pas de remplacement aveugle dans les archives, issues, contrats d'implantation, chemins techniques ou documents de recette : ces références historiques sont conservées pour leur intégrité. Aucun comportement, sonde, port, processus, job ni autre dépôt modifié.

Tests MAIN non encore exécutés. Version 4.2c14 de correction de libellé uniquement.
