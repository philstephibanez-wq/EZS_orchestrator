# 1.3a(6) — Convention atomique

Contexte : préfixes de commits inconsistants.

Modification : préfixe [vVERSION], VERSION dans le même commit, tests et note de livraison.

Validation : inspection statique GitHub ; aucun test runtime.

Impact : documentation uniquement, sans changement des jobs.

Limites : historique antérieur préservé.
